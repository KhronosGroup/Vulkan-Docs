=== Description

This extension allows applications to control whether non-conformant Vulkan
devices are included in the results of physical device enumeration.
This prevents applications from accidentally using non-conformant devices,
which may lack expected functionality or otherwise diverge from the
requirements of the Vulkan Specification.

The mechanism for identifying an implementation as non-conformant is
specific to each platforms Vulkan loader implementation.
Refer to platform-specific documentation for further details.

This extension is implemented in the loader.
